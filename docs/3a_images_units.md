
# Image Units and Conversion

`radot` provides tools to manage, normalize, and convert voxel units in radioactive images (PET and SPECT), supporting absolute radioactivity (`bq`), activity concentration (`bqml`), body weight standardized uptake value (`suv`), and lean body mass standardized uptake value (`sul`).

---

## Supported Image Units

| Unit | Description | Dimensions / Typical Range | Required Metadata |
| :--- | :--- | :--- | :--- |
| `bq` | Total decay rate in Becquerels per voxel | $\text{Bq} = \text{disintegrations/s}$ | Voxel volume (from image spacing) |
| `bqml` | Activity concentration | $\text{Bq/mL}$ or $\text{Bq/cm}^3$ | Voxel volume |
| `suv` | Standardized Uptake Value (normalized by patient total body weight) | Dimensionless (typically $0.1 - 30$) | Injected activity ($A_{\text{inj}}$ in MBq), Patient body weight ($W$ in kg) |
| `sul` | Standardized Uptake Value normalized by Lean Body Mass (LBM) | Dimensionless | Injected activity, Patient weight, plus height & sex (analytical) or fat segmentation mask |

---

## SUL (Lean Body Mass SUV): Principles & Methods

### Clinical Rationale & Definition
Standardized Uptake Value ($\text{SUV}_{\text{bw}}$) normalizes tracer concentration by total body weight. However, in overweight or obese patients, excess adipose (fat) tissue takes up significantly less hydrophilic radiotracers (such as $^{18}\text{F}\text{-FDG}$ or therapeutic radiopharmaceuticals) than lean tissues. Consequently, $\text{SUV}_{\text{bw}}$ tends to systematically overestimate tumor and organ uptake in patients with high body mass index (BMI).

**SUL** normalizes activity concentration by the patient's **Lean Body Mass (LBM)** instead of total body weight:

$$\text{SUL} = \text{SUV}_{\text{bw}} \cdot \frac{\text{LBM}}{W}$$

where $W$ is total body weight in kg. SUL is the standard metric recommended by clinical PET response criteria, such as **PERCIST** (PET Response Criteria in Solid Tumors).

### Lean Body Mass (LBM) Calculation Strategies

`radot` supports three distinct strategies to compute LBM via `--lbm-method`:

#### 1. Strategy A: James (1976) Formula (`james`)
The classical clinical standard used in PET protocols (including PERCIST):

$$\text{LBM}_{\text{male}} = 1.10 \cdot W - 128 \cdot \left(\frac{W}{H}\right)^2$$

$$\text{LBM}_{\text{female}} = 1.07 \cdot W - 148 \cdot \left(\frac{W}{H}\right)^2$$

where:
- $W$ is patient weight in kg.
- $H$ is patient height in cm.

*(Note: In severely obese patients with $\text{BMI} > 35\text{ kg/m}^2$, the quadratic term can cause the James formula to unrealistically plateau or decrease).*

#### 2. Strategy B: Janmahasatian (2005) Formula (`janmahasatian`)
Derived from a large clinical bioimpedance/dual-energy X-ray absorptiometry (DEXA) cohort, this formula provides monotonic, physiologically realistic LBM estimation across the full spectrum of patient BMIs, especially for overweight and obese individuals:

$$\text{LBM}_{\text{male}} = \frac{9.27 \times 10^3 \cdot W}{6.68 \times 10^3 + 216 \cdot \text{BMI}}$$

$$\text{LBM}_{\text{female}} = \frac{9.27 \times 10^3 \cdot W}{8.78 \times 10^3 + 244 \cdot \text{BMI}}$$

where $\text{BMI} = \frac{W}{(H/100)^2}$ with $H$ in cm and $W$ in kg.

#### 3. Strategy C: Patient-Specific Segmentation (`segmentation`)
When a patient whole-body CT or multi-organ segmentation map is available (e.g., generated by TotalSegmentator), LBM can be determined directly by subtracting the segmented total adipose (fat) mass from total body weight:

$$\text{LBM}_{\text{segmentation}} = W - M_{\text{fat}}$$

Fat mass $M_{\text{fat}}$ (in kg) is determined by integrating the segmented fat volume $V_{\text{fat}}$ (in mL) multiplied by the average physical density of human adipose tissue ($\approx 0.92\text{ g/mL}$):

$$M_{\text{fat}} = V_{\text{fat}} \cdot 0.92 \times 10^{-3}\text{ kg}$$

## Metadata Sidecars & SUL

Image metadata sidecars (`<image>.json`) store normalization parameters so conversion commands can automatically resolve patient attributes without manual re-entry:
- `weight`: Patient body weight in kg.
- `height`: Patient height in cm.
- `sex`: Patient sex (`male` or `female`).
- `unit`: Current image unit (`bq`, `bqml`, `suv`, or `sul`).

To set or inspect patient attributes:
```bash
radot meta spect.nii.gz --sex male --height 175.0 --weight 75.0
```

## Unit Conversion Command

### Converting Units: `radot convert-units`

Converts voxel values of radioactive images (SPECT/PET) between different units: `bq`, `bqml`, `suv`, and `sul`.

```bash
radot convert-units <image_path> -t <to_unit> [options]
```

#### Options:
* `-f, --from-unit <bq|bqml|suv|sul>`: Source unit of the image. If omitted, resolved from the image companion JSON sidecar.
* `-t, --to-unit <bq|bqml|suv|sul>`: Target unit to convert to (Required).
* `-o, --output <output_path>`: Optional path for the converted output file. If omitted, defaults to a modified filename like `<base>_<to-unit>.<ext>`.
* `--weight <float>`: Patient weight in kg (Required for SUV/SUL conversions, if not present in the sidecar).
* `--activity <float>`: Injected activity in MBq (Required for SUV/SUL conversions, if not present in the sidecar).
* `--height <float>`: Patient height in cm (Required for analytical SUL methods, if not present in the sidecar).
* `--sex <male|female>`: Patient sex (Required for analytical SUL methods, if not present in the sidecar).
* `--lbm-method <james|janmahasatian|segmentation>`: Method used to compute Lean Body Mass (LBM). Defaults to `james`.
* `-l, --labels <labels_path>`: Path to a label map image (Required if `--lbm-method segmentation` is used to subtract fat volume).

#### Fat Labels Resolution under `segmentation` method:
When using `--lbm-method segmentation`, the labels are resolved from the companion sidecar JSON of the `--labels` image. A label is identified as fat/adipose tissue (to be subtracted from total body weight) if its lowercase name satisfies either of:
1. Contains the substring `"fat"`, `"adipose"`, or `"lipoma"`.
2. Contains any of the exact clinical abbreviation tokens: `"sat"` (Subcutaneous Adipose Tissue), `"vat"` (Visceral Adipose Tissue), or `"tat"` (Torso Adipose Tissue).

This includes standard TotalSegmentator and TG-263 classes such as:
*   `subcutaneous_fat` / `Fat_Subq`
*   `visceral_fat` / `Fat_Visc`
*   `torso_fat`
*   `VAT_tissue` / `SAT_region`


#### Examples:

1. Convert a SPECT image from Bq/mL to Bq:
```bash
radot convert-units spect.nii.gz -t bq
```

2. Convert a PET image from Bq to SUV, specifying patient weight and injected activity explicitly:
```bash
radot convert-units pet.nii.gz -t suv --weight 75.0 --activity 250.0
```

3. Convert a PET image from SUV to SUL using the James formula:
```bash
radot convert-units pet.nii.gz -t sul --weight 75.0 --height 175.0 --sex male --lbm-method james
```

4. Convert a PET image from SUV to SUL using patient-specific segmentation (subtracting fat mass):
```bash
radot convert-units pet.nii.gz -t sul --weight 75.0 --lbm-method segmentation --labels labels_all.nii.gz
```

## Python API

You can also perform unit conversions programmatically within Python scripts.

### convert_image_units

Converts voxel values of a SimpleITK image in-memory.

```python
import SimpleITK as sitk
from radot import convert_image_units

# Load SPECT image
img = sitk.ReadImage("spect.nii.gz")

# Convert from Bq/mL (bqml) to SUV
suv_img = convert_image_units(
    image=img,
    from_unit="bqml",
    to_unit="suv",
    weight=75.0,
    activity=250.0
)

# Convert from SUV to SUL using the Janmahasatian formula
sul_img = convert_image_units(
    image=suv_img,
    from_unit="suv",
    to_unit="sul",
    weight=75.0,
    height=175.0,
    sex="male",
    lbm_method="janmahasatian"
)
```

---

### convert_image_units_file

Converts units directly between image files and saves the output (automatically updating/creating companion JSON sidecar metadata).

```python
from pathlib import Path
from radot.convert import convert_image_units_file

# Convert a PET file from Bq to SUL using James formula
convert_image_units_file(
    image_path=Path("pet.nii.gz"),
    to_unit="sul",
    from_unit="bq",
    output_path=Path("pet_sul.nii.gz"),
    weight=70.0,
    activity=220.0,
    height=180.0,
    sex="male",
    lbm_method="james"
)
```
