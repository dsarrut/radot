# RADOT (Radiation Dosimetry for Therapy)

`radot` is an open-source Python library and command-line tool suite for radiation dosimetry, image processing, and metadata workflows in targeted radionuclide therapy.

**WARNING : still in early stage of development**

## Installation

```bash
pip install radot
```

CT segmentation (`radot segment`) needs TotalSegmentator (and PyTorch), which is an optional extra:

```bash
pip install "radot[seg]"
```

From the source, for development (tests): `pip install -e ".[dev]"`.

Monte Carlo dose rates (optional, not a radot dependency): radot reads dose-rate maps computed with [OpenGATE](https://github.com/OpenGATE/opengate) (version 10), which is installed separately:

```bash
pip install opengate
```

The first simulation downloads the Geant4 data files. The `opengate_dose_rate` command then computes a dose-rate map from a CT and an activity image (see [Dosimetry Models](https://github.com/dsarrut/radot/blob/main/docs/6a_dose.md#external-dose-rate-map-monte-carlo)).

Shell autocompletion for the CLI, to add to `~/.zshrc` (zsh) or `~/.bashrc` (bash):

```bash
eval "$(_RADOT_COMPLETE=zsh_source radot)"    # zsh
eval "$(_RADOT_COMPLETE=bash_source radot)"   # bash (4.4 or later)
```

## Quick Start

`radot` can be used as a command-line tool (CLI) or as a Python library.

### 1. Command-Line Interface (CLI)

Run `radot` commands directly from your terminal:

```bash
radot dose spect.nii.gz -m ldm --isotope Lu177 --ct ct.nii.gz -o dose.nii.gz
```

### 2. Python Library

Import `radot` and call dosimetry functions directly in your Python code:

```python
from pathlib import Path
from radot.dose import compute_roi_dose_file

compute_roi_dose_file(
    image_path=Path("spect.nii.gz"),
    labels_path=Path("labels.nii.gz"),
    method="madsen2018",
    isotope="Lu177",
    ct_path=Path("ct.nii.gz"),
    method_params={"Liver": {"teff": 45.0}, "Kidney_L": {"teff": 32.0}},
    rois=["Liver", "Kidney_L"],
    output_path=Path("dose.json"),
)
```

For more examples and workflows, see the [Quickstart Guide](https://github.com/dsarrut/radot/blob/main/docs/quickstart.md).

## Core Features

1. **DICOM Conversion**: Converts CT, SPECT, and PET series to NIfTI/NRRD with structured JSON metadata sidecars.

2. **Segmentation**: Automates CT segmentation via TotalSegmentator and remaps labels to standard AAPM TG-263 nomenclature.

3. **Unit Conversion**: Converts image voxel values between `bq`, `bqml`, `suv`, and `sul`

4. **Image Resampling**: Isotropic and grid-matching resampling while strictly preserving total radioactivity.

5. **Radionuclide Physics Data**: Queries ICRP Publication 107 emissions spectra, IAEA LiveChart decay cascades, and OpenDose S-values.

6. **Dosimetry Models**: Implements Local Deposition Model (LDM, voxel-level with daughter cascade support), Hänscheid (2017/2018), and Madsen (2018) single-time-point models, Jackson (2013) for 3 time points, and S-value doses from time-integrated activity (TIA) images.

7. **Monte Carlo Dose Engine**: Uses an external dose-rate map computed with [OpenGATE](https://github.com/OpenGATE/opengate) (`--dose-rate-map`) instead of the S-values or the local deposition: patient anatomy and densities, photons and cross-doses included. The map is scaled to the image activity and combined with the time-integration of the chosen method (Hänscheid 2018, Madsen 2018, physical decay, or none for a TIA image).

## Validation

- **Against Monte Carlo** ([results](https://github.com/dsarrut/radot/blob/main/docs/7_validation_opengate.md)): organ doses compared with OpenGATE simulations on a patient CT, for Lu-177, Y-90, I-131 and Ac-225. Liver self-doses: Madsen 2018 within 6.2 %, LDM within 2 % for Lu-177 and Y-90 (it ignores the photons: −25 % for I-131, as expected), Ac-225 with its decay chain within 3 %. Organ-level cross-doses give the order of magnitude only.
- **Against the SNMMI 177Lu Dosimetry Challenge** ([results](https://github.com/dsarrut/radot/blob/main/docs/8_validation_snmmi.md)): doses from the challenge TIA maps of two patients, compared with the participants' results. All organs and lesions are within 6.5 % of the participants' median (except a liver whose definition differs between participants), with the S-value, LDM and OpenGATE engines; the remaining differences are explained by the organ-mass convention.

Both are run with `pytest validation`; the pages are generated by the scripts in [`validation/`](https://github.com/dsarrut/radot/tree/main/validation/).
